# MarQuesTT

Implementation of MQTT protocol v5.

## Description

This project was created for educational purposes to imporve knowledge in message queueing systems and C# language.
However, it is theriotically possible to use it in project. Yet, it is **_not recommended_** to use it in production.

This project is written with usage of AI Agents.
